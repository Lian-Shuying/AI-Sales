# 企航云帆 - AI决策智能体平台展示

启航云帆的项目书前端展示网站

## 项目简介

企航云帆是一个面向企业全球拓展的 AI 决策智能体平台，具备：
- 🤖 企业级 AI 决策能力
- 🌍 全球拓展支持
- 📊 智能数据分析
- 🚀 高性能集成

## 技术栈

- **框架**: React 18 + Vite
- **样式**: Tailwind CSS + shadcn/ui
- **动画**: Framer Motion
- **3D**: Three.js
- **构建**: Vite

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 项目结构

```
src/
├── components/       # React组件
├── pages/           # 页面
├── lib/             # 工具库
├── styles/          # 全局样式
└── App.jsx
```
